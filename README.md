# ありがとうの花 (sakura-thanks)

> **「“匿名”を、冷笑ではなく、温かい光を感じるコミュニケーションのために。」**  
> ネット世界でネガティブに使われがちな「匿名」をポジティブに再定義し、どこかにいる同級生へ向けて感謝のメッセージを届ける情緒設計（エモーショナルデザイン）のWebサイトです。
---

## 🌸 デザインコンセプト・概要

インターネット初期の温かい「アクセスカウンター」文化と、現代的なエモーショナルデザイン（有機的グラデーション・ネオンアニメーション）を融合させたWebアプリケーションです。

冷淡になりがちなネット空間において、人の心に温かい余韻を残す情報設計を追求。トップ画面のタイトルがタイピングされ、桜の花がそっと揺らめいた後に投稿フォームが浮かび上がる演出など、ユーザー体験（UX）のストーリー性を大切に設計しています。

---

## 🛠 技術規約・環境

* **完全 Vanilla 構成**: HTML5 / CSS3 / JavaScript (ES Modules) 。
* **フォント**: Google Fonts (`DotGothic16`)
* **アセット管理**: 自作SVG (`sakuraSvg.js`) / Figma・Illustratorで書き出したマルチデバイス対応アイコン群

---

## ✨ 主な機能

1. **情緒的な初期アニメーション**
   * タイトルのタイピング風表示（`typeWriter`）
   * 3秒後に浮かび上がる「使い方 ＆ メッセージ入力フォーム」
2. **有機的な背景アニメーション（バニラCSS表現）**
   * CSS `filter: blur()` と `border-radius` の非対称変形を組み合わせ、液体のように溶け合うグラデーションメッシュを演出。
3. **桜のゆらめき・発光エフェクト**
   * 自作SVGパスに対し、キーフレームによる浮遊・色変化（ペールピンク ⇄ ペールブルー）・光彩（ネオンエフェクト）を適用。
4. **メッセージカウンター**
   * 投稿数（初期データ）を8桁のドット風表示へ自動フォーマット（`padStart`）。
5. **SPA風 画面切り替え**
   * 「トップ画面」と「みんなのメッセージ一覧画面」をJavaScriptによるクラス制御でスムーズに遷移。

---

## 💡 こだわりのポイント（UX / パフォーマンス）

* **アンチエイリアス・レスポンシブ最適化**
  * モバイル端末（iPhone Pro Maxサイズ等）でも崩れない可変幅設計（`max-width: 430px` / `dvh` 対応）。
  * iOS Safariでの入力時自動ズームを防ぐため、フォームの文字サイズを16px以上に保ち、CSS側で描画精度（`text-rendering: optimizeLegibility`）を最適化。
* **アセットとMeta情報の標準化**
  * 暗色/明色どちらのタブでも認識しやすいダークグレー単色の `favicon.svg` と、iOS用の `apple-touch-icon.png` を別個設計。
  * SNSシェア時の見映えを担保するため、1200×630pxの OGP画像（`ogp.png`）および Web Manifest 設定（`site.webmanifest`）を完備。

## 🚀 今後の展望 (V2.0〜)

* **Firebase連携によるリアルタイムDB化**
  * 投稿メッセージのリアルタイム反映と、管理者承認（モデレーション機能）を介した安全な公開フローの構築。
* **2回目以降のアクセスにおけるUI最適化**
  * 投稿後、または2回目以降の訪問時にはフォームを「アイコンボタン」化して画面領域を広く確保し、タップ時にモーダル/スライド表示される柔軟なUIへアップデート予定。
